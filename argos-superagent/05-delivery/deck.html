The problem

Upstream: one proactive GitHub coding agent

DeepSeek's dsh-superagent-prototype implements a Router/Worker architecture, immutable Mandates, observe/auto, durable Effects, an Outbox and a human-attention panel. It is a research prototype, not a product.

The design essay goes further: event-driven operation, many-to-many Thread subscriptions, speculative silent execution, Inline & Spill, Chain of Recall, an external semantic Watchdog, channel-specific output budgets, and the attention bottleneck.

Prototype gapNo real sandbox, no external Watchdog, no measured speculation, no native attention metrics.
ARGOS-4 answerSandbox-by-construction pure workers, external Watchdog, speculation ledger, attention meter, replay.
Scope decisionNot a DSH fork. A self-contained showcase that runs here without DSH, GitHub account, Feishu or model key.

Architecture

Domain-agnostic coordination, pluggable Sources

The Engine has no domain vocabulary. Adding a fifth pack changes only the registry, policy and evidence schema.

Four missions

🔬 Helios Replication LabSilent reproduction. Bootstrap CI, 12–16 seed runs, replay stability. Speaks only with an executable effect delta.

📋 Living AuditContinuous control tests, evidence drift, provisional attestation. The human signature is non-delegable.

Authority & attention

Ten invariants, enforced in code

Router never executesWorkers are pure functions in experiments.js; the Engine only enqueues durable effects.
Workers never speakOutbox.send() asserts actor === 'router'; chat replies ≤100 words.
Text is dataUnknown actors and injection fixtures are rejected before a Trigger exists.
Immutable MandatesBound to a policy hash. A policy change invalidates in-flight work; ended Tickets need a new Mandate.
Evidence before proseEvery result has evidence.json, input.json, log.jsonl, report.md, result.json.
Replay & zero credentialsAppend-only JSONL; two runs produce identical 1011-event demo logs. No keys, no network.

Handoff

What it proves — and what it does not

ProvesEvent-driven coordination, attention bounding, evidence-gated delivery, policy revalidation, speculation economics, deterministic replay, four pluggable domains — end to end, with zero credentials.
Does not proveModel quality, real datasets/grids/registries/legal interpretation, OS-level seccomp/container isolation, or production security. Synthetic workload; simulated tools; deterministic reasoning. See production-hardening.md.

Responsible next steps

  • Harden the Worker boundary: container/VM, egress deny, resource caps.
  • Replace synthetic Sources with authenticated real Sources, one at a time, in observe.
  • Re-run the benchmark on real traces; publish p50/p95, attention and cache-read cost together.
  • Only then consider auto for low-risk matched-rule work. Never auto-merge, self-sign or actuate without a signed human Mandate.
